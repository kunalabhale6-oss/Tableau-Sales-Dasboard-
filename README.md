## 📌 Project Overview

The **Sales Performance & Customer Analysis** project is an interactive Tableau dashboard designed to analyze business sales performance and customer-related metrics.

The dashboard provides insights into sales, profit, quantity, and subcategory performance. It also includes year-over-year comparisons to help understand business growth and identify performance trends.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track quantity and other key performance indicators (KPIs).
- Compare current-year and previous-year performance.
- Identify top and bottom-performing subcategories.
- Analyze weekly sales and profit trends.
- Support better business decision-making through data visualization.

## 📊 Dashboard Features

### 1. KPI Analysis
- Total Sales
- Total Profit
- Total Quantity

### 2. Year-over-Year Comparison
- Current Year vs Previous Year
- Percentage difference in Sales
- Percentage difference in Profit
- Percentage difference in Quantity
- Customer and Order comparisons

### 3. Subcategory Analysis
- Sales performance by subcategory
- Profit comparison
- Quantity comparison
- Identification of minimum and maximum performance

### 4. Weekly Trend Analysis
- Weekly Sales Trends
- Weekly Profit Trends
- Performance comparison against average values

### 5. Interactive Features
- Year selection parameter
- Dynamic KPI calculations
- Interactive dashboard visualizations
